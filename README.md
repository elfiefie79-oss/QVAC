# Offline Document Analyzer

Paste any raw text or markdown document and an on-device AI generates instant summaries, key points, or structured breakdowns. Entirely on your machine with Tether's **QVAC SDK**. No cloud call, no API key, no bill.

It calls the QVAC SDK's `loadModel()` and `completion()` functions directly. The app processes text inputs locally on device to ensure complete privacy and data confidentiality for sensitive files.
